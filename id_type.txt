Database table primary ID fields and generation
===============================================

Source: Prisma models in prisma/schema.prisma. Table names use the mapped database table name.

Legend
------
PostgreSQL UUID     = PostgreSQL generates a native UUID with gen_random_uuid().
App UUID            = Prisma Client generates a UUID with @default(uuid()).
App CUID            = Prisma Client generates a CUID with @default(cuid()); this is not a UUID.
Supplied ID         = supplied by an external system/caller; no generation default is declared.
Inherited UUID      = UUID primary key value is supplied from the referenced parent listing ID.
